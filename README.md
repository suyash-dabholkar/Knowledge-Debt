# Knowledge Debt

AI-powered learning system that traces a student's repeated mistakes back to
the root prerequisite gap causing them, and generates a minimal repair path.
Built for the iQOO Hackathon — Smart Education track.

## Structure

- `knowledge-engine/` — Knowledge Graph & Diagnostic Engine (Member 1)
- `ai-engine/` — AI Learning & Debt Repayment Engine (Member 2)
- `frontend/` — Dashboard, graph visualization, quiz UI (Member 3)

See `CONTRIBUTING.md` for the branch workflow.
